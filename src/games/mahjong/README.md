# Mạt Chược — chưa code

Thư mục để dành chỗ. Chưa có luật/state/UI thật — hiện chỉ là 1 thẻ "Sắp ra mắt" ở màn Sảnh (`src/hub/`).

Khi bắt đầu code thật, đi theo đúng cấu trúc như `src/games/bang/` (`core/` thuần không đụng mạng/DOM, `server/`, `client/`) và các quy tắc bất di bất dịch ở `CLAUDE.md` gốc dự án.
