# Ảnh lá bài (việc 4.6)

Thả file PNG vào đây, đặt tên **đúng** theo tên lá (client tự ghép đường dẫn
`/sprites/<tên>.png`, xem `cardImageUrl()` trong `src/client/ui.ts`):

Nền trong suốt, tỉ lệ vuông (1:1) là đẹp nhất — chỉ cần vẽ phần minh hoạ,
KHÔNG cần vẽ tên lá/số/chất (đã hiển thị sẵn bằng chữ đè lên ảnh).

Thiếu ảnh nào thì lá đó vẫn hiển thị bình thường bằng chữ (không vỡ giao
diện) — thêm ảnh tới đâu, gắn tới đó, không cần thêm ảnh nào cũng chơi được.
